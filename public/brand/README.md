# Brand assets

| File | Use |
| --- | --- |
| `xc-mark.svg` | App icon, favicon, social avatar. Blue tile with the woven X. |
| `xc-mark-mono.svg` | Single-colour mark; inherits `currentColor`. For dark backgrounds, stamps, invoices. |
| `xavierconnect-logo.svg` | Horizontal lockup: mark + wordmark + parent endorsement. |

**Concept.** The mark is an X built from two strokes that weave: one passes over the other. Two parties,
one connection. It doubles as the initial of Xavier and holds up at 16px.

**Replacing with the official Xavier Enterprise logo.** If Xavier Enterprise supplies a master logo, drop the SVG
files here with the same names. The site renders the mark through `src/components/brand/logo.tsx`, so no other
code changes are needed.

Clear space: keep at least half the mark's height free on all sides. Minimum size: 20px mark, 120px lockup.
